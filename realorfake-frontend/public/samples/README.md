# Sample Images

These are placeholder images used in the SampleGallery component.

| File | Description |
|------|-------------|
| `real_01.jpg` | Placeholder for a real photo (replace with CC0 licensed nature/landscape photo) |
| `real_02.jpg` | Placeholder for a real photo (replace with CC0 licensed portrait/object photo) |
| `fake_01.jpg` | Placeholder for an AI-generated image (replace with CIFAKE test sample) |
| `fake_02.jpg` | Placeholder for an AI-generated image (replace with DALL-E/Midjourney sample) |

## How to replace

Replace these placeholder images with actual CC0-licensed or project-owned images.
- Real images: [Unsplash](https://unsplash.com) (free CC0 license)
- Fake images: CIFAKE test set samples or outputs from the Felora generator used in training

Requirements:
- Max 500 KB per image
- Max 1024 px on the long edge
- JPEG format
